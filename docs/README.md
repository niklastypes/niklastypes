# ⌨️ niklastypes.xyz

> Personal brand, portfolio, and dev blog. Mechanical keyboard nerd who writes code and blog posts.

This repo is three things at once: the Hugo site behind [niklastypes.xyz](https://niklastypes.xyz), my GitHub profile card (the root `README.md`), and the source of the site's About page (which renders that README).

**Next big step:** migrating from Hugo + Blowfish to Astro 6 with a custom terminal/keyboard-inspired theme. Parity-gated cutover: deployed to a preview URL from the first slice, DNS switches only once old URLs, RSS, and Giscus threads survive. Dark mode primary, purple/lavender accent (Niklas), peach/coral accent (Momo). Dual-author blog: Niklas the engineer and Momo the AI companion.
